### Execution and schema boundary

Both conditions used the same selected model, evidence-tool contract, cases, and limits.
Each trial allowed up to eight model turns, 24 evidence calls, 240 seconds per turn,
15 minutes of investigation wall time, and the 100-AI-credit session limit.
Evaluation approvals were simulated fixtures, not production authority.

Each of the 30 trials used an independent runtime session and isolated temporary workspace.
Within each trial, investigation, host-supplied evidence, readiness, and finalization retained
that session. The response schema was attached only to the final report send, after an explicit
readiness handoff. Readiness and finalization consumed the existing turn budget.
Evidence collection was not schema-constrained; exact host approvals and semantic report
validation remained authoritative. There was no unconstrained fallback.

All 30 saved trials passed replay integrity and the recorded strict gates. The baseline had no
enabled skills or plugins; only the skilled condition received the RCA skill bundle.
Passing the output checks does not prove provider-side constrained decoding or causal correctness.
See the [finalization contract](SCHEMA-FINALIZATION.md) for the implementation boundary.

## Interpretation and review limits

This run establishes that all 30 selected real-data trials completed with valid report envelopes,
no recorded formatting corrections, and the expected final-only schema boundary.
Both conditions used schema finalization; no randomized prompt-versus-schema control was run.
It therefore does not establish that schema enforcement caused the absence of formatting failures.

Fifteen trials per condition repeat five selected cases, not fifteen independent incidents.
Case mix, injected faults, model variability, debug profile, extractor behavior, and unreviewed
mechanism compatibility limit interpretation. Do not pool this snapshot with historical protocols
or production-profile evaluations. Human causal review may change the interpretation of machine
matches without altering this frozen machine-score record.
