Choose RAI Planner to develop a plan and RAI Reviewer to assess the evidence. The included standards references, notices, and plan template stay with these workflows.

## Install

Register the `microsoft/hve-core` marketplace once, then run:

```bash
copilot plugin install hve-sdlc-responsible-ai@hve-core
```

In VS Code, choose `hve-sdlc-responsible-ai` in the same marketplace. Pair with [`hve-sdlc-security`](hve-sdlc-security) or [`hve-sdlc-privacy`](hve-sdlc-privacy) for related assessments if useful; no companion install is required. If you already use [All](hve-core), it contains this topic.

See [RAI Planner](../reference/agents/rai-planning/rai-planner) for an entry point.
