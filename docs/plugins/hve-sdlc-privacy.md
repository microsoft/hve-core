Choose Privacy Planner for a processing activity or Privacy Reviewer for an existing plan or requirements document. These workflows support qualified review; they do not determine legal compliance.

## Install

Register the `microsoft/hve-core` marketplace once, then run:

```bash
copilot plugin install hve-sdlc-privacy@hve-core
```

In VS Code, choose `hve-sdlc-privacy` in the same marketplace. Pair with [`hve-sdlc-security`](hve-sdlc-security) for a security assessment if useful; no companion install is required. If you already use [All](hve-core), it contains this topic.

See [Privacy Planner](../reference/agents/privacy/privacy-planner) for an entry point.
