Choose ADR Creator for an architecture decision, BRD Builder for business outcomes, or PRD Builder for product requirements. The builders carry their own authoring templates and quality reviewers.

## Install

Register the `microsoft/hve-core` marketplace once, then run:

```bash
copilot plugin install hve-project-planning@hve-core
```

In VS Code, choose `hve-project-planning` in the same marketplace. Pair with [`hve-rpi-builder`](hve-rpi-builder) for deeper research if useful; no companion install is required. If you already use [All](hve-core), it contains this topic.

See [Requirements authoring](../reference/skills/project-planning/requirements-author) for an entry point.
