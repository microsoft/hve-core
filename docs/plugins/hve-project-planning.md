Choose ADR Creator for architecture decisions, BRD Builder for business outcomes, PRD Builder for product requirements, Backlog Manager or Functional Planner for work-item planning, UX UI Designer for UX workflows, or Experiment Designer for minimum viable experiments. Skills include architecture and C4 diagrams, SLO planning, and Jira and GitLab workflows.

## Install

Register the `microsoft/hve-core` marketplace once, then run:

```bash
copilot plugin install hve-project-planning@hve-core
```

In VS Code, choose `hve-project-planning` in the same marketplace. Pair with [`hve-base`](hve-base) for deeper research if useful; no companion install is required. If you already use [All](hve-core), it contains this topic.

See [Requirements authoring](../reference/skills/project-planning/requirements-author) for an entry point.
