HVE-Core accessibility vocabulary

Namespace: https://microsoft.github.io/hve-core/ns/accessibility#

These terms extend W3C EARL 1.0 with provenance and review state that EARL does not define. EARL supplies the assertion, outcome, and mode vocabulary; these terms record how the evidence was produced and whether a person has validated it. A machine-readable context is available at context.jsonld.

Why these terms exist

EARL describes a test result but has no way to say that a result is AI-assisted, unreviewed, or produced by a run that did not finish. An accessibility report can travel to a procurement or conformance reader on its own, so that context has to travel with it rather than sitting in a sibling document.

Terms

Vocabulary terms, their expected values, and their meaning
Term Value Meaning
hve:aiAssisted Boolean An AI-assisted process contributed to producing this document.
hve:humanReviewCompleted Boolean A qualified accessibility reviewer has validated these results. False by default. The tool never sets this to true on its own.
hve:evidenceLimits String What the recorded evidence methods can and cannot decide.
hve:toolVersion String Version of the harness that produced the document.
hve:criteriaCatalog Object Identity and review state of the reviewed catalog whose adequacy rules decided each outcome.
hve:quarantined Boolean Derived from a run that ended in an operational failure. The findings are real but the run did not complete, so the document is not a basis for a conformance claim.
hve:quarantineReason String Why the producing run was quarantined.
hve:method String Evidence method that produced the result, such as screen-reader or runtime-automation.
hve:methodAdequacy decides or informs Whether the recorded method can decide the criterion or only raise and lower suspicion about it. A method that only informs never closes a criterion.
hve:state String Interaction state the surface was in when observed.
hve:humanJudgmentRequired Boolean No available method can decide this criterion because doing so depends on judging meaning, quality, or intent.
